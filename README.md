# 🤖 Jarvis AI Assistant — Локальный ИИ-Агент

Продвинутый локальный искусственный интеллект и личный ассистент, вдохновленный каноничным Джарвисом. Проект построен по модульной архитектуре на языке Python и работает **полностью автономно и приватно**, без отправки данных в облачные сервисы.

---

## 🧠 Технологический стек проекта (2026)
*   **Логический движок:** [Ollama](https://ollama.com/) — серверная прослойка для запуска нейросетей.
*   **Языковая модель:** `Qwen 2.5 (14B)` в 4-битном квантовании (Q4_K_M). Оптимальный выбор для работы с кодом и русским языком, целиком помещающийся в видеопамять (VRAM).
*   **Архитектура управления:** **Agent Loop (Цикл Агента)** на базе `ollama.chat` с поддержкой памяти контекста и автономного последовательного вызова инструментов (Tool Calling).
*   **Веб-инструменты:** Библиотека `ddgs` (DuckDuckGo Search API) для умного веб-скрейпинга и поиска медиаконтента.
*   **Генерация документов:** Библиотека `python-docx` для автоматической сборки структурированных файлов Microsoft Word.

---

## 🛠 Текущая архитектура проекта
Проект разделен на логические модули внутри пакета `tools`, что позволяет легко добавлять новые возможности без изменения основного ядра:

```text
jarvis-ai-assistant/
├── .venv/                  # Изолированное виртуальное окружение Python
├── tools/                  # Пакет расширений и инструментов (Руки Джарвиса)
│   ├── __init__.py         # Центральный шлюз инициализации и JSON-схем для Ollama
│   ├── system_commands.py  # Управление ОС Windows (время, завершение работы)
│   └── browser_commands.py # Автономный поиск в сети, парсинг и генерация документов
├── main.py                 # Сердце Джарвиса (Логика диалога, память, цикл Агента)
├── requirements.txt        # Список зафиксированных зависимостей проекта
└── README.md               # Документация проекта
```

## 🔥 Что Джарвис уже умеет делать самостоятельно:
1.  **Держать характер:** Общается вежливо, профессионально и с легкой благородной иронией, обращаясь к создателю «сэр» или «Серго».
2.  **Помнить контекст:** Поддерживает глубокую историю диалога в рамках активной сессии.
3.  **Анализировать интернет:** Если внутренних знаний модели недостаточно, Джарвис сам формулирует поисковые запросы, отправляется в сеть и извлекает сухую выжимку данных.
4.  **Генерировать иллюстрированные отчеты:** Полностью автономно создает файлы `.docx` на Рабочем столе пользователя, самостоятельно подбирая уникальное имя файла, форматируя заголовки (`##`) и скачивая тематические изображения из интернета с автоматической подгонкой ширины под стандарт страницы (12 см).

## 🎛 Инструкция по развертыванию
### Требования к железу
*   Видеокарта: NVIDIA RTX (рекомендуется от **12 ГБ VRAM** для модели 14B).
*   Оперативная память: от **16 ГБ RAM**.

### Шаг 1. Подготовка Ollama в Windows
1. Скачайте и установите **Ollama** с официального сайта.
2. В терминале Windows скачайте модель:
   ```bash
   ollama run qwen2.5:14b
   ```

### Шаг 2. Клонирование и установка зависимостей
1. Клонируйте репозиторий и откройте его в **PyCharm**.
2. В терминале PyCharm с активированным окружением `(.venv)` установите библиотеки:
   ```bash
   pip install ollama pydantic ddgs python-docx requests
   ```
3. Запустите главный файл:
   ```bash
   python main.py
   ```
