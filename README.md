# 🤖 Nova AI Assistant — Автономный Локальный ИИ-Агент

Продвинутый локальный искусственный интеллект и личный ассистент, созданный по модульной архитектуре на языке Python. Проект работает **полностью автономно и приватно** на базе мощностей локального ПК, без отправки данных в облачные сервисы.

---

## 🧠 Технологический стек проекта (2026)
*   **Логический движок:** [Ollama](https://ollama.com) — серверная прослойка для запуска нейросетей.
*   **Языковая модель:** `Qwen 2.5 (14B)` в 4-битном квантовании (Q4_K_M). Идеально сбалансирована под написание кода и русский язык.
*   **Архитектура управления:** **Agent Loop (Цикл Агента)** на базе `ollama.chat` — бесконечный цикл планирования, позволяющий модели последовательно вызывать несколько инструментов за один запрос.
*   **Слух и распознавание речи (STT):** [OpenAI Whisper Medium](https://github.com) — высокоточная нейросеть, развернутая локально на ядрах **NVIDIA CUDA** через движок `faster-whisper`.
*   **Фильтрация звука и речи:** Встроенный нейросетевой **Silero VAD** (Voice Activity Detection) на CUDA для автоматической отсечки тишины и фонового шума.
*   **Синтез речи (TTS):** [Silero TTS V5](https://github.com) — локальное нейросетевое аудио-ядро нового поколения, запущенное на ядрах **NVIDIA CUDA**.
*   **Веб-инструменты:** Библиотека `ddgs` (DuckDuckGo Search API) для умного веб-скрейпинга.
*   **Генерация документов:** Библиотека `python-docx` для автоматической сборки файлов Microsoft Word.

## 🛠 Текущая архитектура проекта
Проект разделен на изолированные логические модули внутри пакета `tools`, что позволяет расширять возможности Новы без изменения основного ядра:

```text
jarvis-ai-assistant/
├── env/                    # Изолированное виртуальное окружение Python (или .venv)
├── tools/                  # Пакет расширений и инструментов (Руки, Слух и Голос Новы)
│   ├── __init__.py         # Центральный шлюз инициализации и JSON-схем для Ollama
│   ├── system_commands.py  # Управление ОС Windows (время, завершение работы)
│   ├── browser_commands.py # Автономный поиск в сети, парсинг и генерация Word-файлов
│   ├── voice_input.py      # Высокоточный слух на базе OpenAI Whisper Medium и WASAPI
│   └── voice_assistant.py  # Локальный синтез речи Новы на базе PyTorch и CUDA
├── main.py                 # Сердце Новы (Логика диалога, динамический временной якорь, Agent Loop)
├── requirements.txt        # Список зафиксированных зависимостей проекта
└── README.md               # Документация проекта
```

## 🔥 Что Нова уже умеет делать самостоятельно:
1.  **Держать характер и контекст:** Общается вежливо, свободно, в женском роде и с легкой благородной иронией. Называет создателя «сэр», «босс», «шеф» или «дон».
2.  **Ориентироваться во времени:** Благодаря динамическому временному якорю в ядре, Нова всегда точно знает текущий день недели, число, месяц и год, полностью исключая временную слепоту локальных моделей.
3.  **Слышать слитную речь:** Высокоточный перехват команды и триггера на одном выдохе (например: *«Нова, какая завтра погода в Рыбинске?»*). Потоковая запись WASAPI жестко привязана к **NVIDIA Broadcast** для аппаратной очистки сигнала.
4.  **Игнорировать цифровой шум:** Нативный C++ Silero VAD полностью уничтожает галлюцинации нейросети, фантомные щелчки и субтитры в моменты молчания.
5.  **Работать в режиме Агента:** Сама планирует цепочки действий (например: Шаг 1 — пойти в поиск, Шаг 2 — проанализировать данные, Шаг 3 — вызвать функцию записи в файл).
6.  **Генерировать иллюстрированные отчеты:** Автономно создает структурированные файлы `.docx` на Рабочем столе, сама придумывает им английские имена по теме запроса, форматирует заголовки (`##`) и скачивает тематические изображения из интернета с автоподгоном ширины под стандарт страницы (12 см).
7.  **Разговаривать вслух:** Моментально озвучивает свои ответы приятным женским голосом прямо из динамиков ПК, используя тензорные мощности видеокарты.

## 💾 Критически важное расположение компонентов ИИ
Чтобы обойти баги библиотек C++ и PyTorch, которые не умеют читать русскую кириллицу в путях Windows (например, в папке `учеба`), тяжелые файлы вынесены в безопасные англоязычные директории:

*   **Модель голоса (Silero V5):** Должна быть скачана вручную и находиться строго по пути:  
    👉 `C:\voiceModel\v5_ru.pt`
*   **Кэш моделей распознавания (Hugging Face Hub):** Автоматически создается в профиле пользователя Windows:  
    👉 `C:\Users\<Имя_Пользователя>\.cache\huggingface\hub\`
*   **Библиотеки вычислений:** Тяжелый пакет `torch` и `faster-whisper` с CUDA-зависимостями развернуты локально внутри изолированного окружения `env/`.

## 🎛 Инструкция по развертыванию
### Требования к железу
*   Процессор: От 6 ядер (рекомендуется уровень **AMD Ryzen 5 7500F** и выше).
*   Видеокарта: NVIDIA GeForce (строго рекомендуется **RTX 4070 12GB** или аналоги с тензорными ядрами и поддержкой CUDA).
*   Оперативная память: от **16 ГБ RAM** (оптимально 32 ГБ).
*   Микрофон: Студийный USB-микрофон (например, **Samson C01U Pro**) с настроенным системным аудио-стеком **NVIDIA Broadcast** (WASAPI-драйвер).

### Шаг 1. Подготовка Ollama и языковой модели
1. Установите **Ollama** с официального сайта.
2. Скачайте модель в терминале Windows:
   ```bash
   ollama run qwen2.5:14b
   ```

### Шаг 2. Развертывание кода и окружения
1. Включите **Режим разработчика (Developer Mode)** в настройках Windows для корректной работы кэша Hugging Face.
2. Откройте проект в **PyCharm**, убедитесь в активности окружения `(env)`.
3. Скачайте файл голоса `v5_ru.pt` and положите его в `C:\voiceModel\`.
4. Установите все зависимости одной командой:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите главный файл:
   ```bash
   python main.py
   ```
